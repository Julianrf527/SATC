# Este archivo era una copia del requirements del backend completo: traía
# SQLAlchemy, asyncpg, psycopg2, MinIO, pyclamd, pypdf, python-magic, passlib,
# bcrypt, APScheduler, aiosmtplib, holidays, aiofiles, loguru, python-multipart
# y email-validator, ninguno de los cuales importa el gateway. El gateway no
# tiene base de datos, no toca disco, no manda correo y no procesa archivos:
# solo enruta. Cada paquete de más era superficie de vulnerabilidades (y CVEs
# que auditar) sin ninguna función, además de imagen y tiempo de build.
#
# Todo lo que queda está respaldado por un import real:
#   fastapi, starlette   -> main.py
#   uvicorn, gunicorn    -> proceso de arranque (Dockerfile CMD)
#   python-jose[crypto]  -> utils/funciones.py (jwe)
#   httpx[http2]         -> main.py (proxy) y el HEALTHCHECK del Dockerfile
#   python-dotenv        -> main.py, utils/funciones.py
#   redis[asyncio]       -> utils/redis_client.py, utils/rate_limit.py
#   pytz / tzdata        -> zona horaria America/Bogota
#
# pydantic no se lista: no se importa directamente, entra como dependencia
# obligatoria de fastapi.
